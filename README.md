# UI 용어집

바이브코딩을 할 때 사람과 AI가 화면을 **같은 이름**으로 부르게 하는 업무 화면 UI·모션 용어 62개입니다.

**페이지**: https://whitejo401.github.io/ui-labs/

"사이드 팝업 띄워줘"라고 하면 AI는 가운데 Modal을 띄울 수도, 사이드바 메뉴를 만들 수도 있습니다. 이 용어집은 그런 말을 Drawer, Modal Dialog처럼 정해 둔 이름으로 바꾸고, 그대로 복사해 쓸 요청 문장을 줍니다.

## 페이지에서 할 수 있는 것

- **용어 62개**를 묶음(구조·표현·움직임·만들기)과 태그(목적, 쓰임, 시작 조건, 만들기 난이도)로 찾기
- 용어마다 **움직이는 예시**와 장면 막대(시간 값 t를 끌어 한 장면씩 보기), **조절판**
- 조절판 값을 바꾸면 **요청 문장**도 같이 바뀌고, 복사 단추로 가져가기
- **헷갈리는 짝**과 **틀리기 쉬운 말**
- **조합 화면 5개**(이슈 목록, 이슈 상세, 대시보드, 업무 보드, 신청·설정): 용어를 엮어 실제로 눌러 보는 화면. "용어 보기"를 켜면 부품마다 이름표가 붙고, 이름표를 누르면 그 용어가 열립니다

## AI 세션에서 쓰기

- [`llms.txt`](https://whitejo401.github.io/ui-labs/llms.txt): 용어마다 한 줄 설명, 헷갈리는 짝, 요청 예를 담은 요약
- [`terms.json`](terms.json): 용어 전체 데이터
- [`recipes.json`](recipes.json): 조합 화면과 화면 하나를 통째로 만드는 요청 문장

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 페이지 틀: 검색, 필터, 용어 카드, 조합 화면 탭 |
| `parts.css` | 예시 부품의 꼴. 밝은 화면·어두운 화면 색 |
| `parts.js` | 용어 62개의 예시 장면. 모두 시간 값 t(0~1)로 그린다 |
| `screen-*.js` | 조합 화면 5개 |
| `terms.json`, `recipes.json` | 데이터 |
| `tools/make_llms.py` | `terms.json`에서 `llms.txt`를 만든다 |

빌드 없이 정적 파일만으로 돕니다. 내 컴퓨터에서 볼 때는 `python3 -m http.server`로 열어 주세요(파일을 바로 열면 `terms.json`을 읽지 못합니다).
