# UI 도감

바이브코딩을 할 때 사람과 AI가 화면을 **같은 이름**으로 부르게 하는 UI·모션 도감입니다. 용어 197개를 담습니다: 업무 화면 부품 62개, 묶기·스크롤 39개, 소개·랜딩 효과 28개, 차트·시각화 52개(차트 종류, 부품, 조작, 모션, 기법), 발표 자료 16개(다이어그램 10개, 슬라이드 6개).

예전 이름은 "UI 용어집"입니다. 주소는 그대로입니다.

**페이지**: https://whitejo401.github.io/ui-labs/

"사이드 팝업 띄워줘"라고 하면 AI는 가운데 Modal을 띄울 수도, 사이드바 메뉴를 만들 수도 있습니다. 이 도감은 그런 말을 Drawer, Modal Dialog처럼 정해 둔 이름으로 바꾸고, 그대로 복사해 쓸 요청 문장을 줍니다.

## 페이지에서 할 수 있는 것

- **첫 화면 시연**: "사이드 팝업 띄워줘" 같은 애매한 말 하나가 두 화면으로 갈리는 모습과, 각각을 정확히 요청하는 문장
- **용어 전체**를 묶음(구조·표현·움직임·만들기)과 태그(목적, 쓰임, 시작 조건, 만들기 난이도)로 찾기. 위에 붙는 도구 막대에서 검색, 필터, 소묶음 바로 가기
- 카드마다 **줄인 예시 미리보기**와 요청 문장 바로 복사
- 용어마다 **움직이는 예시**와 장면 막대(시간 값 t를 끌어 한 장면씩 보기), **조절판**
- 조절판 값을 바꾸면 **요청 문장**도 같이 바뀌고, 복사 단추로 가져가기
- **헷갈리는 짝**과 **틀리기 쉬운 말**
- **조합 화면 16개**(업무 화면 이슈 목록, 이슈 상세, 대시보드, 업무 보드, 신청·설정과 제품 소개 랜딩, 분석·보고서, 데이터 스토리, 도움말 문서, 설정 페이지, 상품 목록, 그룹 구분, 코드 열람기, 연락처 목록, 설명·발표 덱, 보고서 덱): 용어를 엮어 실제로 눌러 보는 화면. "용어 보기"를 켜면 부품마다 이름표가 붙고, 이름표를 누르면 그 용어가 열립니다
- **설명·발표 덱**: 사내 문서 질의응답 시스템을 설명하는 10장 덱(예시 내용). 장마다 미리 보고, PowerPoint에서 고칠 수 있는 `.pptx`(도형과 글이 모두 기본 개체, 발표자 노트 포함)로 내려받고, 장 내용을 바꿔 넣을 입력 JSON을 복사
- **보고서 덱**: 시범 결과를 보고하는 8장 덱(예시 내용). 흰 바탕 보고서 꼴에 지표 카드·막대·선·누적 막대 차트·데이터 표. 같은 장 목록으로 `.pptx`와 목차 있는 HTML 문서를 내려받음
- 맨 위 예시 상자의 **이 예시의 용어 보기**: 예시의 부품(말 한 줄의 Typewriter, 갈래 선의 Line Draw, 견주는 두 화면, 요청 문장의 Stagger)에 이름표. 이름표를 누르면 그 용어 카드가 열립니다
- **테마**: 밝게·어둡게·시스템 설정 따르기. 고른 값은 그 브라우저에만 기억

## AI 세션에서 쓰기

- [`llms.txt`](https://whitejo401.github.io/ui-labs/llms.txt): 용어마다 한 줄 설명, 헷갈리는 짝, 요청 예를 담은 요약과 조합 화면 요청 문장
- [`terms.json`](terms.json): 용어 전체 데이터
- [`recipes.json`](recipes.json): 조합 화면과 화면 하나를 통째로 만드는 요청 문장

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 페이지 틀: 첫 화면 시연, 검색, 필터, 용어 카드, 조합 화면 탭, 테마 |
| `parts.css` | 예시 부품의 꼴. 밝은 화면·어두운 화면 색 |
| `parts.js` | 모든 용어의 예시 장면. 모두 시간 값 t(0~1)로 그린다 |
| `screen-*.js` | 조합 화면 16개. `screen-deck.js`는 `recipes.json`에서 장 목록(`slides`)이 있는 항목을 덱 화면으로 만든다 |
| `slides.js` | 슬라이드 생성기: 장 하나 → 배치 함수(칸 길이 검사, 글자 폭 재기) → 도형 목록 → SVG. 다이어그램·슬라이드 용어의 예시 장면도 여기 있다 |
| `slides-pptx.js` | 같은 도형 목록 → `.pptx`. 내려받기를 누를 때 `vendor/pptxgen.bundle.js`를 불러온다 |
| `slides-doc.js` | 같은 덱 → 목차 있는 HTML 문서. 장마다 절 하나(제목, 결론 문장, 본문 그림) |
| `vendor/` | [PptxGenJS](https://github.com/gitbrent/PptxGenJS) 4.0.1 묶음 파일(MIT, 안에 든 JSZip도 MIT)과 라이선스 |
| `terms.json`, `recipes.json` | 데이터 |
| `tools/make_llms.py` | `terms.json`에서 `llms.txt`를 만든다 |
| `tools/artifact_fragment.py` | `index.html`에서 Claude 아티팩트에 올릴 페이지 조각을 만든다 |

빌드 없이 정적 파일만으로 돕니다. 내 컴퓨터에서 볼 때는 `python3 -m http.server`로 열어 주세요(파일을 바로 열면 `terms.json`을 읽지 못합니다).
