UI 용어집

바이브코딩을 할 때 사람과 AI가 화면을 같은 이름으로 부르게 하는 용어집입니다. 용어를 누르면 헷갈리는 짝, 틀리기 쉬운 말, 그대로 복사해 쓸 요청 문장이 나옵니다.

필터
    용어 개 · 데이터는 terms.json, 조합 화면은 recipes.json입니다. 용어마다 움직이는 예시가 있고, 조합 화면은 7개입니다. 업무 화면 5개가 업무 화면 용어 62개를 한 번씩 쓰고, 제품 소개 랜딩이 소개·랜딩 효과를, 분석·보고서가 차트 용어 32개를 모두 엮습니다. 코드는 MIT, 글은 CC BY 4.0 · GitHub · llms.txt
